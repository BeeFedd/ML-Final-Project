# Оценка качества автомобилей (Car Evaluation Predictor)

## Суть работы

Данный проект представляет собой ML-сервис для предсказания качества автомобилей на основе их характеристик.

В ходе работы было выполнено следующее:
1. **Анализ данных и машинное обучение**: В Jupyter Notebook (`Final Project/model/final_project.ipynb`) был исследован датасет и обучена модель градиентного бустинга **CatBoost**.
2. **Сохранение модели**: Обученная модель была сериализована и сохранена в файл (`Final Project/model/catboost_model.cbm`) для дальнейшего использования в продакшене.
3. **Разработка REST API сервиса**: На базе **FastAPI** написан сервис, который загружает модель и предоставляет к ней доступ по сети. 
   - На вход сервис принимает характеристики авто: покупательскую цену, стоимость обслуживания, количество дверей, вместимость (в людях), размер багажника и оценку безопасности.
   - В качестве ответа сервис выдает один из четырех классов качества: `unacc` (неприемлемо), `acc` (приемлемо), `good` (хорошо) или `vgood` (очень хорошо).
4. **Валидация данных**: Вся входная и выходная информация строго типизирована с использованием Pydantic и Enum, благодаря чему генерируется понятная документация, а все поля ввода превращаются в удобные выпадающие списки (dropdown) в интерфейсе Swagger.

## Структура проекта

- `Final Project/model/` — данные для обучения (`data.csv`), Jupyter ноутбук с экспериментами и готовая модель CatBoost.
- `Final Project/app/` — исходный код веб-сервиса (настройки FastAPI, схемы запросов/ответов, обработчики роутов и сервисный слой с инференсом модели).
- `pyproject.toml` и `uv.lock` — конфигурация зависимостей. Для управления пакетами используется современный менеджер **uv**.

## Запуск Swagger UI и сервиса

Для работы с проектом рекомендуется использовать пакетный менеджер [uv](https://docs.astral.sh/uv/).

1. Находясь в корневой директории проекта (там, где расположен `pyproject.toml`), установите все зависимости:
   ```bash
   uv sync
   ```

2. Запустите веб-сервер в режиме разработчика (с автоперезагрузкой при изменениях кода):
   ```bash
   uv run fastapi dev "Final Project/app/main.py"
   ```

3. **Как открыть Swagger**:
   После успешного запуска сервера откройте ваш веб-браузер и перейдите по ссылке:
   👉 **http://127.0.0.1:8000/docs**

   Откроется интерактивная документация Swagger UI. Чтобы сделать предсказание:
   - Раскройте блок `POST /predict`.
   - Нажмите кнопку **"Try it out"**.
   - Выберите нужные значения характеристик автомобиля из предложенных выпадающих списков.
   - Нажмите **"Execute"**, чтобы отправить запрос к модели и получить предсказание.
